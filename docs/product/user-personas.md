# User Personas / ユーザーペルソナ

## Persona 1: 営業マネージャー — 田中 健太 / Kenta Tanaka

| Attribute | Detail |
|---|---|
| Role | 営業マネージャー（10 名チーム） |
| Age | 38 |
| Tech literacy | 中 — CRM は使える、AI ツールは試した程度 |
| Goal | チームの案件進行を可視化し、提案書作成を効率化 |
| Pain | CRM と ChatGPT が別々、調査結果が提案書に反映されない |
| Regapro usage | 案件一覧 → タスク割当 → 調査レビュー → 成果物承認 |

**Quote:** 「AI に聞くより、案件の中で調査から提案まで一気通貫でやりたい。」

## Persona 2: フィールドセールス — 佐藤 美咲 / Misaki Sato

| Attribute | Detail |
|---|---|
| Role | フィールドセールス |
| Age | 29 |
| Tech literacy | 中〜高 — スマホ中心 |
| Goal | 移動中にタスク確認、商談前の調査、議事録作成 |
| Pain | PC 前提の CRM、モバイルで使いにくい |
| Regapro usage | モバイルで今日のタスク → 顧客履歴 → 調査確認 → 議事録下書き |

**Quote:** 「商談前にスマホでサッと調査結果を見たい。チャットじゃなくて、案件に紐づいて。」

## Persona 3: コンサルタント — 鈴木 大輔 / Daisuke Suzuki

| Attribute | Detail |
|---|---|
| Role | 独立コンサルタント |
| Age | 45 |
| Tech literacy | 高 |
| Goal | 複数案件の調査・レポートを効率的に管理 |
| Pain | Notion + Google + ChatGPT の行き来、ソース管理が煩雑 |
| Regapro usage | 案件ごとに調査セッション → ソース整理 → レポート成果物 |

**Quote:** 「ソース付きの調査メモがそのままレポートの下書きになれば理想。」

## Persona 4: 管理者 — 山本 由紀 / Yuki Yamamoto

| Attribute | Detail |
|---|---|
| Role | 情シス / 管理部 |
| Age | 42 |
| Tech literacy | 高 |
| Goal | メンバー管理、権限設定、データセキュリティ |
| Pain | AI ツールのシャドー IT、データ持ち出しリスク |
| Regapro usage | 設定 → メンバー招待 → ロール設定 → 監査ログ確認 |

**Quote:** 「AI は使わせたいが、データが外部に出ない仕組みが必要。」

## Persona 5: パワーユーザー — Alex Chen

| Attribute | Detail |
|---|---|
| Role | シニア PM（グローバルチーム） |
| Age | 34 |
| Tech literacy | 非常に高 |
| Goal | キーボード操作、API 連携、カスタムワークフロー |
| Pain | GUI だけのツールは遅い |
| Regapro usage | Cmd+K → 案件検索 → キーボードショートカット → 設定で LLM 選択 |

**Quote:** 「UI はシンプルでいい。裏で Provider を差し替えられるのが重要。」

## Anti-Persona / 非ターゲット

| Persona | Why Not |
|---|---|
| カジュアル AI チャットユーザー | 汎用チャットは ChatGPT 等で十分 |
| エンタープライズ CRM 導入済み大企業 | 既存 CRM との統合要件が複雑 |
| ノーコードダッシュボード愛好家 | KPI カード中心の UI は提供しない |
